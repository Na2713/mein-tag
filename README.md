# Mein Tag 🌸

Eine kleine To-do-App fürs Handy: Beim Öffnen zeigt sie die Aufgaben für heute als abhakbare Liste.
Wiederkehrende und einmalige Aufgaben, Kategorien in Pastellfarben, Wochenübersicht, Export und Import.

- Reines HTML, CSS und JavaScript – ohne Frameworks und Build-Tools
- Progressive Web App: lässt sich zum Homescreen hinzufügen und funktioniert offline
- Alle Daten bleiben auf dem eigenen Gerät (localStorage), kein Konto, kein Server

Die Tests der Wiederholungslogik laufen im Browser: `tests.html` öffnen.
